# My Neovim Config

My nvim configs for my personal Linux machines and MacOS work laptop.

Currently still learning and experimenting, trying to slowly move off of VSCode. Using [kickstart](https://github.com/nvim-lua/kickstart.nvim) as starting point.

## Pre-reqs

- nvim
- git
- ripgrep
- fd-find
- tree-sitter
- unzip
- gcc
- make

## Setup

Symlink this repo to `~/.config/nvim`, eg:

```bash
ln -s <this-repo-path> ~/.config/nvim
```
